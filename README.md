## Featured Projects

### [Tazelyx](https://github.com/omer-damar/Tazelyx)

A smart pantry mobile application that uses receipt OCR and AI-assisted product recognition to track food, reduce waste and provide gamified feedback. Built with React Native, TypeScript, Node.js, Express and MongoDB.

### [Tripay E-ATM](https://github.com/omer-damar/Tripay-E-ATM-Web)

A multi-service electronic ATM system combining an [ASP.NET Core MVC web application](https://github.com/omer-damar/Tripay-E-ATM-Web) with a [Node.js service layer](https://github.com/omer-damar/Tripay-E-ATM-Services). The project integrates REST, gRPC and SOAP services, JWT-based authentication and PostgreSQL.

### [Internship Tracker](https://github.com/omer-damar/InternshipTrackerDemo)

A collaborative native iOS application for tracking internship applications and discovering remote jobs. Built with SwiftUI, SwiftData, MapKit and the Remotive API using Clean Architecture and MVVM.

### [WLP Hybrid Algorithm](https://github.com/omer-damar/WLP-Hibrit-Algoritma)

A Python-based hybrid solution for the Warehouse Location Problem, combining K-Means, greedy selection and local search while comparing results with alternative optimization methods.

### [VisionGuard AI](https://github.com/omer-damar/VisionGuard_AI)

A collaborative image-forgery detection project combining a WPF desktop interface, FastAPI, ResNet18 and traditional computer-vision algorithms.

### [AI-Generated Article Detection](https://github.com/omer-damar/Makale-AI-Tespiti)

A machine-learning project that compares multiple classification algorithms for distinguishing AI-generated and human-written article abstracts.

### [English–Turkish Vocabulary Learning App](https://github.com/omer-damar/sozluk_uygulama)

A C# Windows Forms application with SQL Server that combines vocabulary management, spaced-repetition quizzes, progress analytics, Wordle and word-chain games.
